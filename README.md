# FitLog

FitLog is a modern workout tracking web application that helps users discover exercises, save workouts for later, and create a personalized workout plan for the day.

## Features

- Browse workouts from the FitLog API
- Responsive workout library with workout cards
- View detailed information about each workout
- Add workouts to Today's Plan
- Save workouts for later
- View live Plan and Saved counters in the navbar
- Mark planned workouts as completed
- Remove workouts from Today's Plan or Saved
- Sort workouts by duration, name, calories, or rating
- Workout action toast notifications
- Persistent Plan, Saved, and completed workout data using localStorage
- Responsive design for mobile, tablet, and desktop
- Custom loading and error states
- Custom 404 page

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- Next.js App Router
- REST API
- LocalStorage
